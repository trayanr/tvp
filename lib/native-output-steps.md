`tvp.builder.outputs` supplies explicit installed-output records for canonical
and opt-in owned recipes. Each returns one ordinary named record; the recipe
chooses its order and `.editSteps` can replace, disable or delete it. The legacy
`native-steps.finalize` adapter remains only for retained controls. Compiler and
input discovery belong to the selected base and pure tool providers.

Each record declares its Python/binary tools and invokes absolute paths. Recipe
arguments select tools; record fields select scope and flags. Runtime settings
are operative specification data consumed through `final.runtime`, separately
from public development requirements. MPFR, Fontconfig and Zstd select runtime
providers; Ruby uses named providers with a guarded derived library summary.
JSON-C requires base/self/libm only and exposes optional ELF lookup directories.
An RPATH edit neither relinks code nor proves ABI compatibility.

`copyArtifacts` copies an installed artifact independently across an explicit
`steps.split` boundary. `relocateText` replaces only declared text prefixes.
Required source-epoch data must be exported explicitly for the fresh workspace.
Nix rejects final references to the internal artifact output; no arbitrary
binary relocation is implied.

Pass `outputs = final.outputs` to `copyArtifacts` for either one output or
several. An explicit list must contain every declared output. Omitting the list
retains the single-output shorthand. `preserveHardlinks = false` makes private
file copies when later operations must modify files independently.

Every installed-output helper accepts `output ? "out"`. Select a declared output
by name; its `paths`, template `@OUTPUT@` values and `selfInterpreter` paths then
resolve under that output. For example:

```nix
(outputs.copyArtifacts { inherit coreutils; outputs = final.outputs; })
(outputs.relocateText { inherit python; output = "bin"; paths = [ "lib/pkgconfig" ]; })
(outputs.shebangs {
  inherit python;
  output = "bin";
  paths = [ "bin" ];
  names = [ "sh" ];
  interpreter = "${bash}/bin/bash";
})
```

Text and authoritative RPATH relocation use the matching artifact output's
prefix. References to other artifact outputs need an explicit recipe operation;
the helpers do not infer cross-output mappings. Invalid or undeclared output
names fail during evaluation. Selecting another output leaves the operation's
step name unchanged; repeated operations still need distinct names as below.

Selectors are output-relative files or directories, without empty, `.` or `..`
components. Missing selectors fail. Symlink selectors and symlinked parents
fail; recursive file selection skips discovered symlinks. File operations are
serial and deduplicate device/inode pairs. This assumes the runner's exclusive
ownership of its output, without concurrent writers.

* `output.strip` handles native ELF64 little-endian x86_64 executables and shared
  objects, using selected `readelf` and `strip`. Default arguments are `-S -p`.
  Text and archives are skipped. Optional `elfKinds` selects runtime and/or
  relocatable ELF through the validated object adapter; other platforms fail.
  Archives use the separate `stripArchives` operation below.
* `output.libtool` only prunes nonempty single-quoted `dependency_libs` in
  `.la` files tagged as generated by Libtool with exactly one empty
  `old_library` assignment. It retains the legacy `#pruned` marker, other bytes,
  mode, inode and timestamps. Static and untagged metadata are left alone.
  No metadata is sourced or evaluated.
* `output.rpaths` with explicit `base` and `libraries` selects authoritative
  non-base ELF lookup providers, rebases copied artifact self paths, shrinks
  unused paths, retains required base/self paths and appends declared dlopen
  directories. Recipes pass edited runtime fields to this operation. The
  retained adapter without a library selection only shrinks/appends paths.
  Valid static ELF skips patchelf; malformed input and tool errors fail.
  Relocatable objects cannot receive RPATH operations.
* `output.development` writes each selected development input followed by one
  space, without a newline, to `nix-support/propagated-build-inputs`, and exports
  those same selected requirements as evaluation data for pure discovery. These
  are public header/consumer requirements, never the entire build graph. MPFR
  selects GMP; JSON-C selects none. Symlinked metadata/directories fail.
* `output.check-symlinks` validates the explicitly selected relative, existing,
  internally resolved symlinks. MPFR already installs its expected library
  links and layout; this operation does not rewrite them.
* `output.check-paths` separately audits dynamic ELF search paths, interpreters
  and pathname-bearing DT_NEEDED entries. It rejects nonabsolute, noncanonical,
  missing, shared-build-root and per-step-TMP lookup paths (including ancestor
  lookup directories). `$ORIGIN` expansion and generic wrapper/script auditing
  are not implemented. Arbitrary embedded strings, including assertion source
  filenames, are not runtime lookup paths and are not scanned.

The strip and Libtool controls draw on the correctness lessons of Nixpkgs'
setup hooks; its MIT notice is retained in `bases/stdenv/COPYING`. These helpers
implement no hook dispatcher or generic layout policy. Interpreter processing
uses the separate explicit operation below; recipes own manual compression. `checks.native-output` exercises the implemented behavior
with real ELF tools and recipe/edit contracts.

Two additional helpers return ordinary records for explicit use by recipes:

* `stripArchives { python; binutils; paths; }` strips debug data from normal
  GNU archives of native x86_64 ELF objects, then restores their index with
  `ranlib -D`. Both tools must succeed before installed bytes change. Hardlinks,
  modes and timestamps survive. Thin, empty, malformed, foreign and LTO archives
  are rejected; unrelated files in directory selections are skipped.
* `shebangs { python; paths; names; interpreter ? null;
  selfInterpreter ? null; }` processes executable scripts matching the selected
  interpreter basenames. Choose exactly one absolute interpreter or a path
  relative to the output, such as `selfInterpreter = "bin/ruby"`. There is no
  PATH search. Direct optional arguments are preserved. Plain `env NAME` and
  argument-free `env -S NAME` become direct shebangs. Matching env options,
  assignments, quoting and argument-bearing forms fail explicitly. Body bytes,
  hardlinks, modes and timestamps survive; nonexecutable files remain unchanged.
  Unsupported env syntax mentioning a selected name may fail conservatively,
  even when that name occurs in an argument to another interpreter.

For example:

```nix
tvp.builder.outputs.shebangs {
  inherit python;
  paths = [ "bin" ];
  names = [ "ruby" ];
  selfInterpreter = "bin/ruby";
}
```

Use `steps.sequence [ record [ record record ] ]` to compose a visible plan.
Only one level of groups is accepted; existing name and duplicate validation
still applies. Disabled payloads stay lazy. To use a helper twice, give its
returned record a distinct name with `// { name = "output.other-scripts"; }`.

`rpaths` additionally accepts `workspaceRoot ? null` for a shrink-only operation
before installation. Null retains the existing record and command exactly. A
non-null selector resolves beneath the runner's immutable `TVP_SOURCE_ROOT`
(the workspace directory, independent of step `cwd`); `paths` then selects files
beneath that directory. Both scopes reject empty, absolute, missing, dot/traversal
and symlinked components. Discovered symlinks are skipped as with output scopes.
This mode cannot be combined with authoritative `base`/`libraries`/`forceRpath`.
It also cannot select a nondefault installed `output`.
It reuses the existing ELF classification and shrink/dlopen/timestamp operations.
For example, the JDK selects `source/build/tvp-release` with `paths = [ "jdk" ]`
between `exploded-image` and `images`, before native resources are embedded.
`checks.owned-jdk-source-stage` uses miniature source and native ELF fixtures;
it does not build OpenJDK or execute installed JDK controls.
