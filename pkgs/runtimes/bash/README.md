# Bash family

The registered5.2.37 release uses one inline recipe/release record, the implicit
family constructor/base helpers and one installed `{package,lib,context}` suite.
Ncurses6 remains the actual public library choice. GNU17 and additional configure
flags are grouped editable build facts. The bundled Readline/wide-curses/loadable
profile, `bin/sh`, bashbug, Makefile.inc and self-runtime-path repairs are retained.

The installed-artifact/final split and equal-width artifact name are unchanged.
Standard tools come from the effective base. Existing self-helper/safety programs
keep their paths and bytes. Installed assertions include the original bounded
arith/array/assoc shipped scripts, helper-boundary controls and a loadable module.

The existing shared owned-split test helper still makes a private checked recipe
that inserts test preparation/check commands before installation. It rebuilds
that private recipe and does not restore A. This known reuse/isolation debt is
explicit; the authoring pass does not invent a checkpoint protocol or claim a
full Bash conformance suite. Native shipped-test fixtures remain independent U.

The old construction factory is `retained.nix`; its original stdenv procedure and
installed assertions remain byte-exact under `retained/` and `tests/default.nix`.
GCC13/seed/bootstrap shell providers are not redirected to public Bash.

No Nix evaluation/build/runtime checks were performed by this proposal. Root
must compare producers, reuse exact proofs and validate any changed boundary.
All existing failures and admission/hardening holds remain unwaived.
