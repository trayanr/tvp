# glibc 2.39 source boundary

A configures, compiles and installs the full existing profile. It generates
C.utf8 with the source localedata, imports Linux headers, copies licenses, creates
libdir aliases, and installs the complete raw out/bin layout. F receives the
complete explicit named output map; corresponding A/F roots have equal widths.
F copies, transports supported paths and rebinds installed scripts. No localedef,
localedata or source tree is an F input. out/bin, platform.dynamicLinker and
mkTools retain their interfaces. All ten installed factory controls remain.
There is no newly claimed strict upstream acceptance or runtime qualification.

Field classification:

* A: src/version/patches, base, bash/perl (source directives), gcc/binutils,
  linuxHeaders, buildCC/targetCC/targetCXX, cflags/configureFlags/makeFlags,
  platform and its libcLibdirAliases, bison, python3Minimal, gnumake, unpack and
  preparation tools. Direct dependency edits retain their construction effects.
* F: finalizerScript and installed-script rebinding. mkTools independently binds
  the requested future Bash/Perl; it does not change A. Final step edits reuse A.
* Shared: coreutils and Python are explicit production and packaging tools.
  outputs and artifactName define the transport, not independent runtime knobs.
* R/U: existing factory-installed controls remain separate; no producer gates A/F.

finalize.py explicitly imports the supplied standalone ELF inspector. The policy
recognizes loader/prefix/sysconf/cache/preload/trusted-library, locale/gconv/i18n,
zoneinfo and getconf constants in readonly ELF/static members, exact text paths,
and known self PT_INTERP with matching program headers. It preserves widths,
modes, timestamps and internal aliases. Both virtual namespaces and every payload
are validated before writes; only changed files are staged. Unknown byte owners,
constants, text roles, external links or malformed archives fail closed. Linux
header aliases are the only external namespace exception, with an explicit root.
Cross-output getconf aliases are relinked after both copies are transported.
No general binary prefix mode or loader RPATH shrink is used.

Later, one bounded latest qualification must inspect actual emitted strings and
static members, pooled suffixes/lengths, both output exclusions, diagnostics,
preload/cache/conf paths, static/dynamic/static-PIE and dlopen/iconv/locale defaults,
linker scripts, getconf -ef and mkTools. Exact emitted layout remains unproved;
existing loader-hardening nonpasses remain open and unwaived.
