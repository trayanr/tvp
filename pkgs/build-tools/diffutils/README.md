# diffutils authoring

`default.nix` holds literal releases beside their complete root procedures, package dependencies and narrow source options. `mkFamily` supplies the current construction base, helper tools and shared installed-test context. Earlier stage callers use the explicit `constructionRecipe` captured under `retained/`; the public index has no old-constructor fallback.

A compiles and installs production outputs and saves the existing source-tree checkpoint. F finalizes a private artifact copy and removes the checkpoint. The independent `upstream` leaf restores A, prepares test frontends and runs the original full suite; an upstream failure does not invalidate A/F. Installed assertions live under `tests/` and retain historical guards and skips. This source stage itself claims no new runtime qualification.
